# 研究产物约定

`artifacts/` 用于保存模型研究和验收证据，不是服务运行时目录。

- `baseline/`：默认模型的冻结基线、输入哈希和逐日预测。
- `evaluation/`：独立测试期的候选比较、验收合同与指标。
- `research/`：开发过程中的固定研究报告和相关证据。
- `run/`：日常命令生成的本地 CSV，Git 忽略。
- `tmp/`：短期实验、临时比对和可随时重建的结果，Git 忽略。

不要覆盖 `baseline/`、`evaluation/` 或 `research/` 中已存在的文件。若需要重新评估，请创建新的、带日期或版本号的输出目录；验收工具也会拒绝覆盖既有目录。

预测服务的 SQLite 数据库、每日原始行情归档和发布快照不在这里，而是在 `config.ini` 的 `数据目录`（默认 `service_data/`）中。
