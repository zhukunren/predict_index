# 历史文件归档

此目录保存从项目根目录整理出的历史预测结果和参考资料。归档文件保留原始文件名，完整性由 `manifest.json` 中的 SHA-256 记录。

- `legacy_results/`：历史命令行预测与循环验证输出；
- `reference/`：论文与旧项目压缩包等参考资料；
- `manifest.json`：原始路径、归档路径和哈希清单。

这些文件是历史副本，不参与服务的不可变账本，也不作为模型输入。保留中文脚本的默认输出路径是为了兼容既有命令：未传入 `--output` 时，它们仍可能在项目根目录生成新的实时输出。新的手工输出请明确写入 `artifacts/run/`。

缓存、pytest 临时目录和已忽略的测试产物不归档，可按需重新生成。
